Amazon Sales Analysis Dashboard – Power BI
📊 Project Overview

An interactive Amazon Sales Analysis Dashboard developed using Microsoft Power BI to analyze sales performance, product categories, customer reviews, and sales trends.

🎯 Objectives
Analyze overall sales performance
Compare YTD and QTD sales
Identify top-performing product categories
Analyze monthly and weekly sales trends
Identify top products based on sales and reviews
Provide interactive filtering for business analysis
